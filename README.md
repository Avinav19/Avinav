# 🦁 AVINAV

A Python-based system and internet information tool.

## 🚀 Installation

Open Termux and run:

    git clone https://github.com/Avinav19/Avinav.git
    cd Avinav
    python run.py

## ✨ Features

- System Information
- Live System Monitor
- Battery Information
- Storage Analyzer
- Network Speed Test
- Running Process Monitor
- Large File Finder
- CPU Temperature
- Device Information
- System Diagnostics
- Python Package Manager
- Internet Latency Tester
